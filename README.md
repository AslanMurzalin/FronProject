# CS2 FACEIT Baiting Analyzer

An evidence-first tactical analysis tool that analyzes CS2 match demos (`.dem` / `.dem.zst`) on Mirage to help reviewers distinguish legitimate tactical roles from recurring baiting patterns.

## Getting Started

### Prerequisites
- Python 3.12+

### Installation
```bash
pip install -r requirements.txt
```

### Running Tests
```bash
pytest
```
